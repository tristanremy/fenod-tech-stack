# Use Starlight for the Fenod Stack Handbook

We use Astro Starlight as the publishing platform for the Fenod Stack Handbook at `stack.fenod.fr` because the handbook is primarily structured documentation: Markdown-first, bilingual, searchable, fast on Cloudflare Pages, and easy for AI agents to edit through normal repo diffs. We considered Fumadocs, Docusaurus, Nextra, and Obsidian-style publishing, but Starlight best matches the stack's Astro/Cloudflare defaults while keeping maintenance low.
