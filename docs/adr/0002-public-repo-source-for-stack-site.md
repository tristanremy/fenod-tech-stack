# Use this public repo as the source for stack.fenod.fr

The `fenod-tech-stack` repository remains public and is the source for the public indexed site at `stack.fenod.fr`. This makes the stack handbook transparent, easy to share, and directly usable by humans and AI agents, but it means private operating notes, customer/project-specific infrastructure, credentials, internal approver groups, and unreleased plans must live outside this repo rather than merely being hidden from the Starlight sidebar.
