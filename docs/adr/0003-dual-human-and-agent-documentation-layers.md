# Maintain dual human and agent documentation layers

The Fenod Stack Handbook uses human-readable Starlight guides plus compact Agent Contracts such as AI Index, Stack Contract, Agent Operating Contract, Gotchas, Recipes, `llms.txt`, and `llms-full.txt`. This avoids forcing one format to serve two different readers: humans need rationale, tradeoffs, diagrams, and examples, while AI agents need concise defaults, prohibitions, gotchas, and verification commands.
